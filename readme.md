# LIBRARY MANAGEMENT

This is a minmalistic library management api. This api handles but not limited to the creation of students, library attendants, authors and books. It also handles the borrowing and returning of books by students.

## 🛠️ Tools and Library Used

1. Node Js (Runtime Engine).
2. Express Js (Javascript Backend Framework).
3. Mongoose (Schema model).
4. Mongo DB (Database Engine).
5. Nodemon (Automatic running of node.js server).

## 🌐 Link to documentation

View the documentation to this project 👉🏾 [Documentation](https://library-management-api.docs.buildwithfern.com/node-library-management/create-book)

## 📍 Setup

To run this project locally, follow the following steps:

1. Clone this repo:

```bash
git clone git@github.com:Towbee05/tsacademy-library-management.git
cd tsacademy-library-management
```

.
2. Install the required packages

```bash
npm install
```

.
3. Create a .env file containing your mongodb connection uri
4. Run the project

```bash
npm run dev
```
